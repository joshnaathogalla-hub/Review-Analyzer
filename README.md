# Project Review Analyzer


Project Review Analyzer is an AI-powered web application that analyzes reviews or feedback using Natural Language Processing (NLP). The application detects whether the entered review is Positive or Negative and provides a confidence score for the prediction.

This project helps organizations, businesses, and teams understand customer or employee sentiment quickly and efficiently.

---
 Features
- Real-time sentiment analysis
- Detects Positive and Negative reviews
- Displays prediction confidence score
- Simple and interactive user interface
- Built using Machine Learning and NLP
- Streamlit-based web application

---

 Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- NLP (Natural Language Processing)
- Machine Learning
